# AI Email Generator

## Project Description
An AI-powered system that generates professional business emails
based on context, tone, and key points.

## Features
- Context-aware email generation
- Tone-based writing
- Two subject line options
- Professional email structure

## Inputs
- Situation / Context
- Desired Tone
- Key Points

## Outputs
- Two Subject Lines
- Email Body
- Preview Line
- Writing Style Explanation

## Tech Stack
- Python
- OpenAI API
- Web Interface
